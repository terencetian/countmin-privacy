分刻是一款完全在本机运行的时间手帐应用，没有账号、没有服务器、不收集数据。反馈问题时，请尽量附上设备型号、系统版本、App 版本与复现步骤，这样能更快定位。

联系方式

GitHub Issues（推荐） 打开公开问题列表，点右上角「New issue」描述你的问题或建议。无需 App 账号，GitHub 账号即可。

如果你是通过 TestFlight 安装的测试用户，也可以直接使用 TestFlight App 内置的评价与反馈入口，反馈会连同设备信息一起送达。

提交反馈前请确认

  • App 版本：在「设置 → 关于」查看版本号与 build 号。
  • 复现步骤：做了什么操作、期待什么结果、实际发生了什么。
  • 数据相关：分刻不提供云同步，跨设备迁移请用「更多 → 数据管理」的本地备份导出与导入。
  • 隐私相关：应用不申请网络权限，也不含第三方 SDK；详见隐私政策。

常见问题

卸载后数据还在吗？不在。分刻只把记录存在当前设备，卸载或使用「清除所有数据」都会删除本机记录，且无法由开发者恢复。请定期在「更多 → 数据管理」导出备份。

iPhone 和 iPad 怎么同步？分刻没有云同步。请在旧设备导出 JSON 备份，再在新设备导入；导入会覆盖目标设备上的同份数据。

iPad 上布局为什么和 iPhone 不同？iPad 横屏为左右双栏，竖屏与 iPhone 一致为单列，属于设计口径，不是故障。

Countmin is a time-journal app that runs entirely on your device. There is no account, no server, and no data collection. When reporting an issue, please include your device model, iOS version, app version, and steps to reproduce.

Contact

GitHub Issues (recommended) Open the public issue list and tap "New issue" to describe your question or suggestion. No app account needed — just a GitHub account.

If you installed the app through TestFlight, you can also use the built-in rating and feedback option in the TestFlight app; device details are included automatically.

Before you send feedback

  • App version: check under "Settings → About" for the version and build number.
  • Steps to reproduce: what you did, what you expected, and what actually happened.
  • Data: Countmin has no cloud sync. Move data between devices via local backup export/import under "More → Data Management".
  • Privacy: the app requests no network permission and contains no third-party SDKs. See the Privacy Policy.

Frequently asked questions

Is my data kept after uninstalling? No. Records live only on the current device. Uninstalling or using "Clear All Data" deletes them permanently, and the developer cannot restore them. Export a backup regularly under "More → Data Management".

How do I sync between iPhone and iPad? Countmin has no cloud sync. Export a JSON backup on the old device and import it on the new one; importing overwrites the matching data on the target device.

Why does iPad look different from iPhone? iPad uses a two-column layout in landscape and the same single-column layout as iPhone in portrait. This is intentional, not a bug.
